### Security note
- The current travel-api context helper reads `X-Tenant-ID` / `X-Merchant-ID` headers. These headers MUST be populated by the authenticated merchant gateway and must not be accepted directly from an untrusted public client in production. The next merchant-api2 integration step will make that trust boundary explicit.
